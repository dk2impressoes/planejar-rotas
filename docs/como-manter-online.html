🧭 Planejar Rotas — Como manter online

Guia simples. Tudo gratuito. Versão de 23/11/2026.

1. Como funciona, em uma página

🌐 O siteO aplicativo fica num endereço na internet (gratuito, no GitHub). Quem tiver o link usa no celular ou no computador.
🤖 O robôTodo dia, sozinho, ele busca preços de combustível (ANP), pedágios (ARTESP e outras bases), feriados e regras do rodízio, e atualiza o site.
📱 Os aparelhosAo abrir o app com internet, ele baixa os dados novos sozinho. Sem internet, usa os últimos dados salvos.
Resumo: você publica uma vez (passos 2 e 3). Depois disso, o robô mantém tudo atualizado. Você só age quando receber um aviso dele (passo 7).

2. Publicar o site (uma vez, cerca de 20 minutos)

  1. Crie uma conta gratuita em github.com (botão Sign up) e confirme o e-mail.
  2. Instale o programa gratuito GitHub Desktop (desktop.github.com) e entre com a sua conta.
  3. Extraia o arquivo PlanejarRotas-Repositorio.zip numa pasta, por exemplo Documentos\planejar-rotas.
  4. No GitHub Desktop: File → Add local repository → escolha a pasta. Se ele perguntar, clique em create a repository.
  5. Clique em Publish repository. Desmarque Keep this code private (o site precisa ser público) e confirme.
  6. No site do GitHub, abra o seu repositório → Settings → Pages → em Source, escolha GitHub Actions.
  7. Ainda em Settings → Actions → General → em Workflow permissions, marque Read and write permissions → Save.
  8. Abra a aba Actions → Publicar no GitHub Pages → Run workflow. Em 2 ou 3 minutos aparece um ✓ verde.
O endereço do seu app fica assim: https://SEU-USUARIO.github.io/planejar-rotas/
Está em Settings → Pages. Guarde esse endereço: é ele que você manda para as pessoas.
Por que GitHub Desktop e não “Upload files” no site? O upload pelo site às vezes não envia a pasta .github (onde mora o robô), porque o nome começa com ponto. O GitHub Desktop envia tudo.

3. Ligar o robô de atualização

  1. Aba Actions → Atualizar dados → Run workflow (primeira vez, para testar).
  2. Quando terminar com ✓, ele publica o site sozinho com os dados novos.
  3. A partir daí, ele roda todo dia de manhã, sem você fazer nada.
O robô nunca apaga um dado bom: se uma fonte estiver fora do ar, ele mantém a versão anterior e avisa você.

4. Instalar no celular (é o “instalador do aplicativo”)

Android (Chrome)iPhone (Safari)
  1. Abra o endereço do app.
  2. Toque em ⋮ (canto de cima).
  3. Toque em Instalar app ou Adicionar à tela inicial.
  1. Abra o endereço do app no Safari.
  2. Toque em Compartilhar (quadrado com seta).
  3. Toque em Adicionar à Tela de Início.

O ícone aparece junto com os outros aplicativos. Ele se atualiza sozinho quando há versão nova: o app mostra “Há uma versão nova — Atualizar agora”.

Quer um arquivo APK (Android)? Com o site publicado, entre em pwabuilder.com, cole o endereço do app → Package for stores → Android → Generate. Baixe o pacote, guarde a chave de assinatura em lugar seguro e envie o arquivo assetlinks.json para a pasta site/.well-known/ do repositório.

5. Instalar no Windows

  1. No app, abra Menu → Baixar e instalar e toque em Baixar para Windows. Ou use o arquivo Planejar Rotas - INSTALAR no Windows.exe.
  2. Dois cliques nele → Sim. Não precisa de administrador.
  3. Se aparecer “O Windows protegeu o computador”: Mais informações → Executar assim mesmo (aparece porque o programa não tem assinatura digital paga).
  4. Use o atalho Planejar Rotas na Área de Trabalho ou no menu Iniciar.
  5. Para remover: Configurações → Aplicativos → Aplicativos instalados → Planejar Rotas → Desinstalar.
Apareceu “Uma política de Controle de Aplicativo bloqueou este arquivo”? É o “Controle Inteligente de Aplicativos” do Windows 11, que só aceita programas com assinatura digital paga. Use o arquivo Planejar Rotas - INSTALAR no Windows (se o exe for bloqueado).zip: extraia e dê dois cliques em INSTALAR (clique duas vezes). O resultado é o mesmo.
Para atualizar sozinho: abra no Bloco de Notas o arquivo %LOCALAPPDATA%\PlanejarRotas\config.json e coloque o endereço do app:
"endereco_site": "https://SEU-USUARIO.github.io/planejar-rotas/"
Toda vez que abrir com internet, ele baixa a versão e os dados novos (e confere cada arquivo antes de trocar).

6. O que é automático e o que é com você

Automático (robô e app)Com você (quando receber aviso)
  • Preço do combustível da ANP, por estado e por cidade (toda semana).
  • Tabela oficial de pedágios da ARTESP.
  • Praças de pedágio (base aberta do Sem Parar).
  • Feriados e verificação das regras do rodízio.
  • App baixa tudo ao abrir; botão 🔄 Atualizar para buscar na hora.
  • Responder aos avisos (aba Issues do repositório).
  • Pedir uma pesquisa de tarifas quando o aviso “Pedir pesquisa de tarifas” aparecer (ou enviar uma planilha).
  • Incluir suspensões do rodízio anunciadas pela CET (o robô avisa nas épocas certas).

7. Pesquisa de tarifas sob pedido

Algumas concessionárias não publicam tabelas que o robô consiga ler. Para essas praças:

  1. O robô abre um aviso “Pedir pesquisa de tarifas” com a lista das praças sem valor ou com valor de mais de um ano.
  2. Você pede a pesquisa (ou faz uma planilha no mesmo formato da “Pedagios_Brasil_carros_e_motos”).
  3. A planilha é importada com scripts/importar_pesquisa_pedagios.py e entra na próxima atualização.
Ordem das fontes de cada praça: 1ª tabela oficial → 2ª pesquisa enviada → 3ª notícia da concessionária → 4ª base anterior. Vale o valor mais recente. No app, o usuário sempre pode corrigir o valor e tocar em 💾 Salvar valores.

8. Problemas comuns

O que aconteceuO que fazer
A aba Actions mostra ✗ vermelhoClique no ✗ para ver a mensagem. Quase sempre é uma fonte fora do ar: o robô tenta de novo amanhã e mantém os dados anteriores.
O app mostra a versão antigaToque em Atualizar agora no aviso, ou feche e abra o app de novo.
“Não conseguimos o preço automático”Sem internet ou fonte fora do ar. Digite o preço do litro; o app avisa quando o automático voltar.
Pedágio “sem valor”Use “Pedágios → Ver detalhes e corrigir valores” e peça uma pesquisa (passo 7).
Trocou de celularNo celular antigo: Menu → Salvar cópia. No novo: Menu → abrir cópia.
